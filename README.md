# ShirAmiram

<div dir="rtl" lang="he">

אפליקציה קטנה ללימוד אוצר מילים באנגלית דרך מילות שיר.

**אתר חי:** https://swissystem7.github.io/ShirAmiram/

## מה יש בה

- **שיר:** מילות שיר עם מילים מודגשות. לחיצה על מילה מציגה תרגום לעברית, סוג המילה ומשפט לדוגמה. כפתור הניגון מפעיל מנגינה קצרה שחוזרת, טיימר, והשורה הנוכחית מודגשת. אפשר לשנות מהירות ולגרור את סרגל ההתקדמות.
- **אוצר מילים:** טבלה של כל המילים, עם חיפוש (באנגלית או בעברית) וסינון לפי סוג המילה.
- **מבחן:** ארבע שאלות אמריקאיות עם משוב מיידי, ציון וכפתור להתחלה מחדש.

## מקור התוכן

מילות השיר נכתבו עבור האפליקציה. הן אינן לקוחות משיר שפורסם. המנגינה מסונתזת בדפדפן, בלי קובץ שמע.

## קבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | הדף והחיבור למסך |
| `app.js` | הנתונים והלוגיקה: אוצר המילים, המבחן, הסינון, מיקום השיר |
| `shiramiram_vocab_full.json` | אוצר המילים כקובץ נתונים. בדיקה מוודאת שהוא זהה לרשימה שב-`app.js` |
| `test/app.test.js` | בדיקות אוטומטיות |

## הרצה ובדיקות

אין שלב בנייה. פותחים את `index.html` דרך שרת סטטי כלשהו, למשל:

```bash
npx serve .
```

בדיקות (Node 18 ומעלה, בלי התקנות):

```bash
npm test
```

## מה עדיין חסר

- **מטרה ובעלים:** לא הוגדר למי האפליקציה מיועדת. השם מרמז על הכנה למבחן אמיר״ם, אבל זה לא נקבע.
- **רישיון:** אין קובץ `LICENSE`.
- **CI:** הבדיקות רצות מקומית בלבד. אין הרצה אוטומטית ב-GitHub.

- **שמע:** המנגינה היא צליל מסונתז פשוט, לא שירה של המילים.
