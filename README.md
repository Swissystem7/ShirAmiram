# ShirAmiram (שיראמיר״ם) v1.0

<div dir="rtl" lang="he">

פלטפורמה אינטראקטיבית מלאה להכנה מקיפה למבחני **אמיר״ם / אמי״ר (Amiram / Amir)** דרך מוזיקה, שירים וטכנולוגיות למידה מתקדמות.

**אתר חי:** https://swissystem7.github.io/ShirAmiram/

---

## מה כוללת המערכת (גרסה 1.0)

### 1. עיצוב מתקדם וממשק מובייל מלא (UI/UX)
- ערכת נושא כהה מודרנית (Dark Theme: `#0f172a`, `#1e293b`, `#6366f1`) עם אפקטי Glassmorphism.
- ניווט טאבים נוח (Pill Navigation) מותאם מובייל (עמידה מלאה בתקן נגישות 44px+ tap targets, אפס גלילה אופקית).
- תמיכה מלאה כ-Progressive Web App (PWA) עם Service Worker לעבודה 100% אופליין.

### 2. מאגר אוצר מילים מקיף (300 מילות אמיר״ם)
- 300 מילות מפתח ממוינות בקפידה לפי רמות קושי רשמיות של המרכז הארצי לבחינות ולהערכה (מאל״ו):
  - **רמה A (Foundational):** 100 מילים לרמת בסיס.
  - **רמה B (Intermediate):** 100 מילים לרמת ביניים לקראת פטור.
  - **רמה C (Advanced):** 100 מילים ברמה אקדמית גבוהה לפטור מלא (C1/C2).
- לכל מילה: הגדרה מלאה בעברית (`חלק דיבר: פירוש`), תרגום, משפט דוגמה והקשר.

### 3. מנוע הגיית שמע גלובלי (Universal Speech Audio)
- כפתורי הגייה (`🔊`) אינטראקטיביים זמינים בכל חלקי האפליקציה: בטבלת אוצר המילים, בכרטיסיות, בשאלות הסימולטור ובמילות השירים.
- מבוסס על Web Speech API סטנדרטי בדפדפן (ללא תלות ברשת).

### 4. כרטיסיות חזרות מרווחות (SRS Leitner Flashcards)
- אלגוריתם Leitner מבוסס מדע הלמידה עם 5 תיבות חזרה ומרווחי זמן מותאמים אישית (0, 1, 3, 7, 14 ימים).
- אנימציית היפוך תלת-ממדית (3D Flip), דירוג שליטה (`Again`, `Hard`, `Good`, `Easy`) ושמירה ב-localStorage.

### 5. סימולטור השלמת משפטים (Cloze Sentence Completion)
- שאלות Cloze אותנטיות ברמות קושי A, B, C וסימולציה מעורבת (25 שאלות).
- מחולל מסיחים חכם לפי חלק דיבר (Part-of-Speech) לקבלת חוויית מבחן אמיתית.

### 6. סימולטור שחבור וניסוח מחדש (Amiram Restatements)
- 30 שאלות שחבור מקוריות (10 לכל רמה) המכסות את כל תבניות המבחן: Inversion, Concession, Conditionals, Modals ועוד.
- תיוג וסיווג שגיאות במסיחים והסבר דקדוקי מפורט בעברית לכל שאלה.

### 7. מדד אמיר״ם ולוח מחוונים אנליטי (Score Estimator 50-150)
- מודל חיזוי ציון אמיר״ם על סקאלה רשמית של 50 עד 150 נקודות.
- מיפוי מיידי לרמות פטור אקדמיות (CEFR: A2, B1, B2, C1 - פטור אקדמי מלא).
- פסי התקדמות לפי רמות A/B/C ותור חזרות על מילים חלשות (Weak Words Review Queue).

### 8. נגן שירים וטלפרומפטר קריוקי אינטראקטיבי (30 Songs Teleprompter)
- מנוע טלפרומפטר מסונכרן לכל 30 השירים במערכת.
- תיוג מילות אמיר״ם זוהרות בתוך השיר, פופאפ תרגום והגדרה בלחיצה, וכפתור מהיר "➕ הוסף ל-SRS".
- איתור קובצי שמע מקומיים וסנכרון LRC מלא.

### 9. סטודיו Suno לשירים מקוריים
- חלוקת כל 300 המילים ל-50 שירי לימוד ייעודיים עם מבנה שיר מלא ופרומפטים מוזיקליים מפורטים.

## הרצה ובדיקות

בדיקות יחידה ואינטגרציה (85/85 בדיקות עוברות):
```bash
npm test
```

בדיקת רספונסיביות מובייל (Playwright):
```bash
python scripts/mobile_ui_check.py
```

הרצה מקומית:
```bash
npx serve .
# או
python -m http.server 8080
```
